# v0.2.2 — Larger cutter work canvas

The cutter workspace gives more room to artwork editing and production sheet layout. Arrangement tools share one row, and smaller outer padding leaves more space for the canvas. Settings controls and panel widths keep their existing sizes.

On short screens, the workspace scrolls instead of squeezing the canvas into a narrow strip. Larger displays use the available window height.

Installed Setup builds receive this release through automatic updates. Open the app to check for the update; it downloads in the background and installs when you close the app, or use **Settings → Restart to update** after saving your project. Portable users should download the new Portable build.

The cutter views were checked at 1280 × 600, 1366 × 768, and 1920 × 1080, with no horizontal overflow. The release workflow also runs formatting, type checks, regression tests, Storybook, and the production build before publishing Windows packages.
