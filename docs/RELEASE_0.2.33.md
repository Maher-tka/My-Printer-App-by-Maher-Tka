# v0.2.33 - Interface refresh and Card Montage improvements

The app has a refreshed interface across the dashboard, settings, jobs, exports,
and production tools, with updated colors, glass surfaces, and clearer controls.

Card Montage now uses the finished PDF page bounds consistently in its preview
and exported sheets, helping artwork align with its intended trim area.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually.
