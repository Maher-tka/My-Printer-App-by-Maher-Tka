# v0.2.21 - Combined PDF sheets and printer stock presets

- Add **Combine files on sheets**: pages from several PDFs, images and prepared
  Word documents fill the same 2/4/6/8/9/12/16-up sheets in selection order.
  Preview navigation, paper totals, copies and duplex estimates follow that choice.
- Save named printer presets directly from Fast Print, including the actual driver
  tray/magazine, paper weight, bypass size, output bin and finishing settings.
  Selecting a saved stock restores its A4/A3 size and color. All saved stocks for
  the selected printer remain available when switching paper sizes.
- Use consistent multi-up photo direction and equal filled photo frames by default.
  Keep independent 90-degree file rotation and editable Portrait/Landscape for
  every normal layout, including 2/6/8-up. Full page restores Original orientation
  and shows the complete source by default.

A4/A3, mixed multipage PDF/photo, manual rotation, copy totals, duplex boundaries
and native-preview/output checks passed locally. Driver presets retain the full
private configuration without changing Windows printer defaults. Physical stock,
magazine/bypass operation and vendor output finishing still need shop verification.
No hardware print jobs were submitted during verification.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually. Saved projects and original
artwork are preserved.
