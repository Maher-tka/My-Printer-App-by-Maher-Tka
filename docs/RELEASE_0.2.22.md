# v0.2.22 - Fast Print page selection and saved ID presets

- Select All pages, Odd pages, Even pages, or a custom range such as `1-5, 8, 12`
  separately for each file. Preview, combined sheets, copy totals and duplex
  estimates follow the selected pages. Invalid ranges block printing.
- Choose saved Settings driver presets directly in ID review. Apply the selected
  printer's paper, black-and-white/color, duplex and tray/vendor settings while
  keeping the ID crops, front/back assignments, sizes, spacing and copy quantity.
  Returning to Printer settings preserves the selected driver snapshot.
- Keep Fast Print responsive while preparing photos and printer settings. Reuse
  unchanged previews and driver snapshots instead of repeating the same work.

Local release checks and hidden production proofs cover page selection, A4/A3,
EN/FR/Arabic RTL, light/dark appearance, low-end mode and ID preset return trips.
All eight ID test photos passed original and off-center +/-45-degree crop and
print-proof checks, including 90 mm widths, matching front/back centers and
unchanged original files. No hardware print jobs were submitted. Actual Epson WF
hardware-driver, workshop tray/stock and live DPI checks remain pending.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually. Saved projects, artwork,
printer presets and Windows printer defaults are preserved.
