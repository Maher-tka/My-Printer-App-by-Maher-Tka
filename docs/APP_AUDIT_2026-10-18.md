# App audit — 2026-10-18

Existing local work was preserved. Fixes were made locally; no release was published.

## Fixed reliability defects

| Finding                                                                                                                                                                                  | Correction                                                                                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hardcover discarded its active session after a failed recovery write when switching tools.                                                                                               | Navigation now waits for a successful recovery write. Failure keeps the current project and shows the existing warning; a successful retry clears that warning. Without the desktop recovery API, the normal unsaved-changes confirmation applies. |
| Scheduled autosave checked rejected IPC calls but ignored resolved `{ ok: false }` disk failures.                                                                                        | Recovery writes now check the operation result and surface failures through the existing recovery warning.                                                                                                                                         |
| Job/customer deletion wrote storage and dispatched notifications inside React state updaters, using potentially stale in-memory lists.                                                   | Deletion reads the current persisted list and completes its write before updating React state.                                                                                                                                                     |
| Optional job fields were not validated by local storage or backup validation. An object-valued deadline could reach React rendering; malformed print history could break later printing. | Shared validation checks optional strings, cost fields, and print-history structure in both paths. Valid older jobs without those fields remain accepted.                                                                                          |
| Job/customer upsert returned more records than it persisted at the 1,000-record limit.                                                                                                   | The returned state now matches the normalized, persisted list.                                                                                                                                                                                     |

## Verification

- `npm run build` passed, including both TypeScript projects. Storybook build passed with bundle-size warnings.
- Formatting checks passed for the files changed during this audit; `git diff --check` passed.
- Browser smoke checks opened all 12 app routes in English/light at 1366×768, French/dark at 1920×1080, and Arabic/dark with low-end mode at 1366×768. No page exceptions or horizontal document overflow were recorded.
- Imported representative PDF/image fixtures into Booklet, Card, Sequential, Cutter, and Hardcover across English/light, French/dark, and Arabic/light low-end configurations: 15 tool/configuration combinations. Clear confirmation, cancellation, clearing, and keyboard focus restoration passed. No horizontal document overflow was recorded.
- Exercised job creation, quote calculation, editing, canceling deletion, deleting a job, preserving its customer, and deleting the customer. No page/console errors were recorded in the job save/edit/delete sequence.
- Simulated a desktop recovery disk failure in the browser: Hardcover retained a 25 mm spine measurement and its current route. A successful retry allowed navigation and carried that measurement in the recovery snapshot. Error-state screenshots were captured at both desktop target sizes.
- Browser artifacts are under `output/playwright/overall-audit/` and `output/playwright/universal-clear/`; detailed command logs are `.codex-overall-*.log`.
