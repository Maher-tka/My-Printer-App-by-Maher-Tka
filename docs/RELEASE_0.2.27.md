# v0.2.27 - A clearer, roomier Fast Print

- Fast Print has a refreshed glass-inspired appearance and a compact, numbered
  pages-per-sheet selector, making presets easier to find.
- New **5 per sheet** and **7 per sheet** presets work with image and PDF
  pages, previews, orientation choices and multi-sheet jobs.
- The Fast Print window opens taller when the available screen space allows it,
  while staying centered and resizable.
- Each new Fast Print session starts with one job copy. The chosen number of
  copies stays in place while changing printers or presets during that session.

Validation includes the release checks and Fast Print preview and output checks,
including English, French and Arabic, light and dark themes, low-end mode, and
real ID and Polaroid photo proofs. No hardware print jobs were sent. Live
high-DPI, mixed-DPI multi-monitor and screen-reader checks remain pending. ID
output uses the chosen fixed height of 55, 56 or 60 mm; a crop with different
proportions can be stretched to that size.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually.
