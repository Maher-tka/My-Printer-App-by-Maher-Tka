# v0.2.3 — Expand the cutter canvas

Use **Expand canvas** in Prepare artwork, Cut lines, or Production Layout to give the work canvas nearly the whole screen. Drawing, selection, undo, zoom, and sheet tools remain available in the expanded view. Use **Restore workspace** or press **Escape** to return to the settings and artwork library.

The settings controls keep their existing sizes. Expanding and restoring the canvas keeps the artwork dimensions, selected objects, quantities, and sheet layout intact.

On a 1366 × 768 screen, the expanded artwork canvas measures 1342 × 588 pixels and the production sheet viewport measures 1340 × 696 pixels. Expansion and restoration were also checked at 1280 × 600. Release validation includes formatting, type checks, regression tests, Storybook, and the production build.

Installed Setup builds download this stable release through the automatic-update feed. Save the open project, then use **Settings → Restart to update** when the download is ready, or close the app to install. Portable users should download the new Portable build.
