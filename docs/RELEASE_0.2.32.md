# v0.2.32 - Fast Print arrangement and card cutting rectangles

In Fast Print, drag an image or page onto another to swap their positions on
the current sheet. You can also select a slot and use Shift with the arrow keys.
The printed output follows the reviewed order. Repeated images can share sheets
with the other selected images. In ordinary layouts, slots stay in the same
positions on partial sheets.

Card Montage now places automatic cutting rectangles on the front only, keeping
the back clean while preserving front and back alignment.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually.
