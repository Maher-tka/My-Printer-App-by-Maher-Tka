# v0.2.31 - PDF Tools

PDF Tools is now available from the dashboard and sidebar. Merge, split,
compress and edit PDFs; convert between PDFs, images and Office files; and
reorder files before merging.

Office-to-PDF conversion requires Microsoft Office or LibreOffice installed on
the PC. Editable Office exports do not perform OCR and may not preserve complex
layouts.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually.
