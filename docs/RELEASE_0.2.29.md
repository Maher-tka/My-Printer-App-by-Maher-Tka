# v0.2.29 - Easier printer preset selection

- Driver presets are grouped by printer in collapsible sections, with counts and
  a warning when a saved printer is unavailable.
- Choose the printer directly when assigning a preset to a print option. Editing
  another preset no longer changes which printer receives that assignment.
- Card Montage groups printer presets by machine and shows the selected preset’s
  printer, paper, color and tray.

Validation covers preset editing, assignment, error recovery, keyboard access,
English, French and Arabic, light and dark themes, and low-end mode. No hardware
print jobs were sent. Native expanded-menu and screen-reader checks remain pending.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually.
