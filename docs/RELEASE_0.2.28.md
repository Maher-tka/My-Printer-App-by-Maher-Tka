# v0.2.28 - Compact Fast Print montage

- Arrange PDF pages and images more closely with **Compact layout**. Combine
  files on a sheet and choose the cutting gap, including zero.
- Keep PDF pages and images at their actual size. PDF dimensions and image DPI
  determine the output size; images without DPI metadata use 96 DPI. Fast Print
  warns if the chosen layout cannot fit at actual size.
- Add optional 0.25 px separation lines and choose their color.

Validation covers A4 and A3 montage previews and prepared output, mixed PDF and
image sizes, rotation, pagination, English, French and Arabic, and light and dark
themes. No hardware print jobs were sent.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually.
