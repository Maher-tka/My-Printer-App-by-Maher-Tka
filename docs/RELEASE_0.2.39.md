# v0.2.39 - ID printer preset and icon fix

Choose a default ID printer preset in **Settings → Printing settings**. New ID
reviews automatically select its printer and saved settings, and the default can
be changed or cleared at any time.

Fixed the preset manager's icon menu so choosing or resetting printer and preset
icons remains reliable when the image picker opens.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually.
