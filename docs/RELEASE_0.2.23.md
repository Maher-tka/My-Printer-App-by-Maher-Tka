# v0.2.23 - Visible printer presets and custom ordering

- Show saved driver presets from all printers in Settings > Printing settings.
  Each entry includes paper, color, duplex and tray details, with an Edit action.
  Update the existing name/driver settings while keeping its preset ID and
  print-option assignments. New preset creates a separate entry.
- Add Saved preset > Arrange presets in Fast Print. Move presets up or down and
  Save their order separately for each printer. Cancel preserves the prior order.
  The same order appears in Fast Print, app settings, ID review and saved-stock
  menus after refreshing or reopening. Renaming keeps a preset's position;
  new presets follow arranged entries.
- Preserve the selected preset and private driver snapshots while arranging.
  Order is stored separately and remains available across launches.

To choose a preset for printing, open Saved preset (Préréglage enregistré in
French), beside Polaroid. Click Automatic / Automatique, choose its name, then
Print or Review ID.

Local checks cover updating existing presets, cancellation/failure, ordering,
new windows, separate printers, unchanged settings and EN/FR/Arabic RTL layouts
in light/dark appearance, including low-end mode. No hardware print jobs were
submitted. Live vendor dialogs, high-DPI and workshop-device checks remain pending.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually. Saved projects, artwork,
printer presets and Windows printer defaults are preserved.
