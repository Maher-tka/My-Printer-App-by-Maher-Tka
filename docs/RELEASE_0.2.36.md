# v0.2.36 - Fast Print improvements

- Fast Print has refreshed light and dark styling and remembers your appearance
  choice. ID review follows the Fast Print theme and can open before sign-in;
  printing still requires access.
- Find saved presets more easily by printer, paper size and color mode. The
  compact layout gives the print preview more room, and Polaroid choices appear
  beneath the ID card layout.
- Adjust brightness from −15% to +15% in regular image and PDF jobs. Each new
  job starts at 0%; the preview and prepared output use the same adjustment.
- The sidebar's selected icon has a cleaner highlight.

Installed Setup builds receive this stable release through automatic updates.
Portable users replace their executable manually.
